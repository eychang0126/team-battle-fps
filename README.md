# 팀 배틀 FPS (1인칭 팀전 웹 총게임)

로비에서 게임을 골라 들어가는 1인칭 웹 게임이에요. **팀 배틀 FPS**, **좀비 모드**, **좀비 웨이브**(혼자서도 OK), **용암 타워**(혼자서도 OK), **점프 타워**가 있어요. PC, 태블릿, 폰에서 할 수 있어요. 2~10명이 홈페이지 주소로 들어와서 함께 해요.

## 들어가는 방법
1. 홈페이지 접속 (입장 비밀번호 없음)
2. 계정 만들기 또는 로그인
3. 로비에서 게임 고르기
4. 게임 시작! (화면 클릭) — Esc를 누르면 '로비로 나가기' 버튼이 있어요

관리자 화면 주소는 `홈페이지주소/admin` 이에요.

## 조작 (PC)
| 키 | 기능 |
|---|---|
| W A S D | 이동 |
| Space | 점프 |
| Shift | 걷기 |
| 마우스 | 조준 |
| 왼쪽 클릭 | 사격 (누르고 있으면 연사) |
| R | 재장전 |
| Tab | 점수판 |
| Esc | 마우스 풀기 |

## 게임 규칙
- 들어오면 인원이 적은 팀에 자동 배정돼요.
- 체력 100. 몸 25, 머리 60 데미지.
- 탄창 25발, 재장전 1.6초.
- 죽으면 3초 뒤 부활. 부활 직후 2초는 무적이에요 (총을 쏘면 무적이 풀려요).
- 먼저 목표 킬(기본 5)을 채우는 팀이 이기고, 6초 뒤 새 라운드가 시작돼요.

## 좀비 모드 규칙
- 2명 이상 모이면 10초 뒤 시작해요. 5명당 1명이 좀비로 시작해요.
- 좀비는 왼쪽 클릭으로 가까운 인간을 잡아요. 잡힌 인간은 좀비가 돼요.
- 좀비는 체력 250, 조금 더 빨라요. 총에 쓰러져도 3초 뒤 다시 일어나요.
- 인간이 3분 동안 한 명이라도 살아남으면 인간 승리, 모두 감염되면 좀비 승리.

## 좀비 웨이브 규칙 (혼자서도 할 수 있어요)

- 맵은 🏙️ 도시예요. 건물 8채, 바깥 계단으로 옥상까지 올라갈 수 있어요. 대신 좀비도 벽을 기어올라 와요!

- 들어오면 6초 뒤 웨이브 1 시작. 봇 좀비가 몰려와서 물어요.
- 웨이브가 올라갈수록 좀비가 많아지고, 빨라지고, 튼튼해져요.
- 쓰러지면 10초 뒤에 부활 (웨이브를 깨면 바로 부활) (혼자면 바로 게임 오버). 모두 쓰러지면 게임 오버 → 🔄 다시 하기 / 🏠 로비로 중에 골라요.
- 웨이브를 깰 때마다 🪙 5코인 + 웨이브 숫자만큼 🏆 트로피 (1웨이브 1개, 2웨이브 2개, 3웨이브 3개 …).
- 전체 최고 기록이 로비 카드에 표시돼요. 중간에 들어와도 바로 같이 싸워요.

## 🎮 미니게임 (로비 아래쪽)
- 🐤 **플래피 버드**: 누르거나 Space로 날갯짓. 토관 10개 넘으면 🪙 20코인 + 🏆 트로피 1개.
- 🦖 **공룡 달리기**: Space/↑ 점프, ↓ 숙이기. 200점 넘으면 🪙 20코인 + 🏆 트로피 1개.
- 트로피는 없어요. 서버가 걸린 시간을 확인해서 너무 빨리 나온 점수는 인정하지 않아요.

## 🌋 용암 타워 규칙 (혼자서도 할 수 있어요)
- 점프 타워와 같은 탑, 빨간 블록과 체크포인트 없음. 8초 뒤 용암이 아래에서 점점 빨리 올라와요.
- 용암에 닿으면 바로 아웃 → 다음 판까지 기다려요. 모두 빠지면 8초 뒤 새 판.
- 꼭대기 🏁에 닿으면 🪙 20코인 (2명 이상이 같이 시작했으면 🏆 트로피도). 가장 빠른 기록이 로비에 표시돼요.

## 🗼 점프 타워 규칙
- 가운데 기둥을 빙글빙글 돌면서 위로 올라가는 타워예요. 5구간, 갈수록 어려워져요.
- 2명 이상 모이면 10초 뒤 출발해요. (혼자일 때는 연습 모드) 제한 시간 6분.
- 먼저 꼭대기 🏁에 닿은 사람이 이기고 🪙 20코인 + 🏆 트로피! 혼자 연습할 때 깨도 🪙 20코인.
- 🔥 작은 빨간 블록을 밟으면 아웃, 체크포인트보다 8m 넘게 떨어져도 체크포인트로 돌아가요.
- 모든 게임은 중간에 들어올 수 있어요.

- 인간 체력은 **150** (좀비 모드의 좀비는 250).

## 💬 관리자 갠톡
- 관리자는 관리자 페이지의 **💬 갠톡** 칸에서 아무 계정에게나 1:1 메시지를 먼저 보낼 수 있어요 (접속 안 했으면 다음에 들어올 때 보여요).
- 플레이어는 로비의 **💬 관리자와 갠톡** 버튼에서 대화 전체를 보고 답장해요. 게임 중에는 알림으로 뜨고, 채팅에 `/관리자 내용`으로 답장해요.

## ✊ 관리자와 가위바위보
- 로비의 **✊ 관리자와 가위바위보** 버튼으로 신청 → 관리자 페이지에서 수락하면 둘 다 ✊✋✌️ 중 하나를 골라요.
- 신청한 사람이 이기면 🪙 50코인. 하루(한국 시간)에 한 번, 비기면 다시 해요.

## 🗺️ 맵
- 🔫 팀 배틀: 🌳 기본 · 🎄 크리스마스 · 🏙️ 도시 중 투표. 처음 시작할 때 10초 동안 투표하고(그동안은 못 싸워요), 판이 끝날 때도 다음 맵을 투표해요. 관리자가 고르면 그 맵으로 정해져요.
- 🧟 좀비 모드, 🧟‍♂️ 좀비 웨이브: 항상 🏙️ 도시.

## 🎵 배경음악
- 브라우저가 직접 연주하는 8비트 오리지널 곡이에요 (음악 파일 없음, 저작권 걱정 없음).
- 로비 / 팀 배틀 / 좀비 모드 / 좀비 웨이브 / 점프 타워 / 용암 타워 / 무기 시험장마다 다른 곡.
- 로비 위쪽 🎵 버튼으로 켜기/끄기, 옆 막대로 소리 크기. 게임 중에는 **M** 키나 Esc 화면의 🎵 버튼.
- 브라우저 규칙 때문에 화면을 한 번 누른 다음부터 소리가 나요.

## 채팅
- 게임 중 `Enter` = 전체 채팅, `T` = 팀 채팅 (폰은 💬 버튼)
- 로비 화면에도 채팅이 있어요. 예전 채팅이 저장돼서 다시 들어와도 보여요 (팀 채팅은 저장 안 해요).
- 게임 중에는 왼쪽 아래 **💬 채팅** 버튼이나 Esc 화면의 **💬 채팅하기**로도 열 수 있어요.
- 로비의 **🎁 코인 보내기** 버튼, 또는 채팅에 `/코인 아이디 숫자` → 친구에게 내 코인 보내기
- 너무 빨리 보내면 잠깐 막혀요. 관리자는 채팅 금지를 걸 수 있어요.

## 맵 투표 (팀전 · 좀비 모드)
- 🌳 기본 맵 / 🎄 크리스마스 맵 중에 투표해요. (PC는 숫자 `1` `2`, 폰은 왼쪽 위 투표 상자를 눌러요)
- 다음 라운드가 시작할 때 다수결로 맵이 바뀌어요.
- 관리자가 고르면(게임 안에서 투표하거나 관리자 화면에서) 관리자가 정한 맵으로 바뀌어요.

## 관리자 계정 (은영 👑)
- 관리자 화면에서 비밀번호로 로그인 → **관리자 계정으로 게임 열기** 버튼
- 또는 게임 첫 화면에서 아이디 `은영` + 관리자 비밀번호로 로그인
- 이름 옆에 👑, 코인 무한(∞)

## 폰 / 태블릿
- 화면을 누르면 전체 화면 + 가로 모드로 바뀌어요. (아이폰은 직접 가로로 돌려 주세요)
- 왼쪽 조이스틱 이동, 오른쪽 화면 드래그로 둘러보기, 버튼으로 사격/점프/재장전/채팅

## 🏆 트로피와 순위
- 게임에서 이길 때마다 🏆 트로피 1개 + 🪙 20코인
- 로비에 트로피 순위(1~10등)와 내 순위가 나와요.

## 코인과 상점
- 게임에서 이기면(이긴 팀/편 전원) 🪙 20코인을 받아요.
- 로비 아래 상점에서 모자, 얼굴, 피부, 머리 스타일, 머리 색, 옷(후드티·스웨터·멜빵바지·원피스·정장·망토·우주복), 윗옷/바지 색, 안경, 날개, 꼬리를 골라 꾸밀 수 있어요. 산 물건은 바로 착용돼요.
- 옷은 팀 배틀 FPS에서는 팀 색(빨강/파랑)으로 바뀌어요. 모양은 그대로예요.
- 미리보기는 게임 속 캐릭터와 똑같은 3D예요. 드래그하면 돌려 볼 수 있어요.
- 성별(남자/여자/중성)은 계정 만들 때 고르고, 상점 미리보기 아래에서 바꿀 수 있어요.
- 관리자 화면에서 코인을 주거나 뺄 수 있어요.
- 관리자 화면 '전체 계정'에서 모든 계정의 코인·트로피·순위를 보고, 트로피 숫자 바꾸기(순위 조정), ⛔ 밴, 🗑 삭제를 할 수 있어요.

## 인터넷에 올리기 (Render 무료)

### 1. GitHub에 올리기
1. https://github.com 에서 가입 후 **New repository** 클릭
2. 이름을 정하고 (예: `team-battle-fps`) **Create repository**
3. **uploading an existing file** 을 눌러서 이 폴더 안의 파일들을 전부 끌어다 놓기
   - `server.js`, `package.json`, `README.md`, `.gitignore`, 그리고 `public` 폴더째로
4. **Commit changes** 클릭

### 2. Render에서 서버 만들기
1. https://render.com 에서 GitHub 계정으로 가입
2. **New + → Web Service** → 방금 만든 저장소 선택
3. 설정:
   - **Runtime**: Node
   - **Build Command**: 비워 두기 (또는 `echo ok`)
   - **Start Command**: `node server.js`
   - **Instance Type**: Free
4. **Environment Variables**(환경변수)에 추가:
   - `ADMIN_PASSWORD` = 관리자 비밀번호
5. **Create Web Service** → 몇 분 기다리면 `https://이름.onrender.com` 주소가 생겨요.

> 관리자 비밀번호는 코드에 적혀 있지 않아요. Render 환경변수에만 넣기 때문에 GitHub 저장소가 공개여도 안전해요.

### 계정이 안 지워지게 하기 (Upstash 무료 데이터베이스)
1. https://upstash.com 에서 가입 (GitHub 계정으로 가능)
2. **Redis → Create Database** → 이름 아무거나, 지역은 Asia(가까운 곳) → Free 플랜으로 만들기
3. 데이터베이스 화면의 **REST API** 부분에서 두 값을 복사:
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`
4. Render → 내 서비스 → **Environment** 에 위 두 이름 그대로 환경변수 추가 → 저장

### 알아 둘 점 (무료 서버)
- 15분 동안 아무도 없으면 서버가 잠들어요. 다음 사람이 들어올 때 깨어나는 데 30초~1분쯤 걸려요.
- Upstash를 연결하지 않으면, 서버가 잠들었다 깨거나 다시 배포할 때 계정과 코인이 지워져요.

## 내 컴퓨터에서 테스트하기

